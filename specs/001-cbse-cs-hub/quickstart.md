# Quick Start: CBSE CS Hub

**Target**: Sumit Vats — local dev setup and first content addition  
**Date**: 2026-04-28

---

## Prerequisites

| Tool | Version | Install |
|------|---------|---------|
| Node.js | 22.x LTS | https://nodejs.org |
| npm | 10.x | Included with Node.js |
| Angular CLI | 21.x | `npm install -g @angular/cli` |
| Git | Any recent | Already installed |

---

## 1. Create the Angular workspace

```powershell
# From the repository root (c:\POC\learning\CBSE_CS_HUB)
ng new cbse-cs-hub --routing --style=css --standalone --skip-git
cd cbse-cs-hub
```

> **Note**: `--skip-git` prevents Angular CLI from re-initialising git inside the subfolder.

---

## 2. Install dependencies

```powershell
# Tailwind CSS v4
npm install tailwindcss @tailwindcss/postcss postcss

# GitHub Pages deployment
ng add angular-cli-ghpages

# PWA support
ng add @angular/pwa --project cbse-cs-hub
```

---

## 3. Configure Tailwind CSS v4

Create `.postcssrc.json` in the project root:

```json
{
  "plugins": {
    "@tailwindcss/postcss": {}
  }
}
```

Replace the contents of `src/styles.css` with:

```css
@import "tailwindcss";

/* Dark mode support */
@custom-variant dark (&:is(.dark *));
```

---

## 4. Configure base href for GitHub Pages

In `angular.json`, find the `"build"` configuration and add:

```json
"baseHref": "/CBSE_CS_HUB/"
```

---

## 5. Create content asset directories

```powershell
mkdir src/assets/content/study-notes/class-11
mkdir src/assets/content/study-notes/class-12
mkdir src/assets/content/sql-questions
mkdir src/assets/content/python-exercises
```

---

## 6. Run the development server

```powershell
ng serve --open
```

App opens at `http://localhost:4200/CBSE_CS_HUB/`

---

## 7. Add your first SQL question

Create `src/assets/content/sql-questions/select.json`:

```json
[
  {
    "id": "sql-select-001",
    "category": "select",
    "questionText": "Write an SQL query to display the Name and Age of all students from the STUDENT table.",
    "answer": "SELECT Name, Age FROM STUDENT;",
    "explanation": "The SELECT statement retrieves specific columns. List column names separated by commas, then specify the source table using FROM.",
    "difficulty": "easy",
    "isPreviousYear": false
  }
]
```

See `contracts/content-schema.md` for the complete JSON format for all content types.

---

## 8. Deploy to GitHub Pages

```powershell
# Build and deploy in one command
ng deploy --base-href=/CBSE_CS_HUB/
```

Site will be live at: `https://<your-github-username>.github.io/CBSE_CS_HUB/`
