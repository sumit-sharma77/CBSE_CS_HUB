## Summary

Build a mobile-first static educational web platform for CBSE Computer Science students (Classes 11 & 12), delivering four core learning modules — Study Notes Library, SQL Practice, Python Practice, and Personal Notes Pad — plus cross-cutting utilities (search, bookmarks, progress tracking, dark/light mode, recently viewed). The platform is a fully static Angular 21 SPA deployed to GitHub Pages, with all user data persisted exclusively in browser localStorage and all educational content served as lazy-loaded JSON assets.

---

## Technical Context

**Language/Version**: TypeScript 5.9.x, JavaScript ES2022+  
**Framework**: Angular 21.2.x (standalone components, Angular Signals, Angular Router)  
**Styling**: Tailwind CSS 4.2.x (PostCSS plugin, class-based dark mode)  
**Storage**: Browser localStorage (all user state); JSON asset files (all content)  
**Testing**: Jasmine + Karma (unit tests on services)  
**Target Platform**: Static web (GitHub Pages) — Chrome, Firefox, Safari, Edge (latest 2 versions each); mobile-first (320px–1440px)  
**Project Type**: Static SPA (Single Page Application)  
**Performance Goals**: Initial load < 2s on mid-range mobile + 4G; initial bundle < 500KB; content JSON lazy-loaded per route  
**Constraints**: No backend; no server-side rendering; no user accounts; GitHub Pages hosting; localStorage ~5MB budget  
**Scale/Scope**: ~50 study chapters, ~70 SQL questions (7 categories × ~10 each), ~80 Python exercises (8 topics × ~10 each), unlimited personal notes (localStorage-bound)

## Core Services Architecture

### `StorageService`
- Wraps `localStorage.getItem / setItem / removeItem`
- Handles JSON serialisation/deserialisation
- Catches `QuotaExceededError` and emits a user-visible warning signal
- Used by all other services; never call localStorage directly in components

### `ThemeService`
- `WritableSignal<'light' | 'dark'>` initialised from localStorage `cbse-theme`
- `effect()`: updates `<html>` class (`dark` / removes `dark`) + saves to localStorage
- Inline `<script>` in `index.html` sets class synchronously before Angular loads (prevents FOUC)

### `BookmarkService`
- `WritableSignal<Bookmark[]>` initialised from `StorageService`
- `toggle(type, itemId, title)` — adds or removes a bookmark; `effect()` syncs to storage
- `isBookmarked(type, itemId)` → `computed(() => ...)` for template binding
- `clear()` — resets bookmarks signal to `[]` and clears from storage

### `ProgressService`
- `WritableSignal<ProgressStore>` with `recordAttempt(module, categoryKey, itemId)` method
- `getCategoryProgress(module, key)` → `computed()` returning `{ attempted, total, percentage }`
- `reset()` clears the signal and storage

### `RecentlyViewedService`
- `WritableSignal<RecentlyViewedEntry[]>` capped at 10
- `track(entry)` — prepends entry, deduplicates by `itemId`, trims to 10; `effect()` syncs to storage
- `clear()` — resets the signal to `[]` and clears from storage

### `SearchService`
- Loads `search-index.json` once via `HttpClient` on first search invocation
- `search(query: string)` returns filtered `SearchIndexEntry[]` using case-insensitive string matching on `title` and `tags` only
- Debounce 300ms applied in the `SearchBar` component signal

**Goal**: Full CRUD notes system with auto-save, search, and export

- Implement `BookmarkService`, `RecentlyViewedService` (used across features)

**Deliverable**: Full notes CRUD works; notes persist across browser sessions; search filters; export downloads file.

## Risks

| Risk | Impact | Mitigation |
|------|--------|-----------|
| Angular 22 RC released during development | Medium — possible breaking changes | Pin `@angular/cli` and `@angular/core` to `^21.2.x` in `package.json` |
| localStorage quota exceeded during testing | Medium — data loss for student | `StorageService` catches `QuotaExceededError`; UI shows warning |
| Highlight.js bundle size pushes over 500KB | High — violates NFR-001 | Use Prism.js (lighter) or hand-roll `<pre>` with CSS token colouring for just Python+SQL |
| GitHub Pages 404 on route refresh | High — SPA routing broken | `angular-cli-ghpages` creates `404.html` redirect automatically; verify in Phase 8 |
| Content JSON grows large (>50 chapters) | Low — lazy loading mitigates | Chapter content loaded per-chapter; index files remain small |
| Dark mode flash on page load | Medium — poor UX | Inline synchronous `<script>` in `index.html` reads `cbse-theme` from localStorage and sets `dark` class before Angular bootstrap |
